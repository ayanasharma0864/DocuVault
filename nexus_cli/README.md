# Nexus CLI

Nexus CLI is the terminal interface planned for DocuVault.

## Purpose
It will allow users to interact with DocuVault document management
features through terminal commands.

## Current implementation
- `client.py` – HTTP client for communicating with the DocuVault API.
- `commands.py` – Entry point for CLI command functionality.
- `__init__.py` – Package initialization.

## Setup
Activate the project's virtual environment:

```bash
source .venv/bin/activate
python -m pip install requests

```
